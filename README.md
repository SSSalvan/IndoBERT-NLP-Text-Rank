# IndoBERT NLP Text Rank

## Overview
This repository focuses on applying state-of-the-art Natural Language Processing techniques to Indonesian text data. Utilizing the IndoBERT large language model, the project performs complex downstream tasks such as document clustering, text ranking, and classification to extract meaningful semantic insights from unstructured local language datasets.

## Technical Architecture
- **Model:** IndoBERT (HuggingFace Transformers)
- **Framework:** PyTorch
- **Machine Learning:** Scikit-Learn (K-Means Clustering)
- **Data Engineering:** Pandas

## Features
- Advanced text tokenization using IndoBERT configurations.
- Unsupervised learning techniques applied to high-dimensional text embeddings.
- Robust evaluation and logging mechanisms.
