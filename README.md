Indonesian NLP Text Analysis

Description
This project applies Natural Language Processing techniques to Indonesian text data. It utilizes the IndoBERT language model for downstream tasks such as classification and information extraction to improve accuracy on local language datasets.

Technologies Used
Python, HuggingFace Transformers, PyTorch, IndoBERT.

How to Run
Ensure you have the required Python packages installed.
Download the pre-trained IndoBERT weights if not cached automatically.
Run the notebook or main script to see the evaluation results.
